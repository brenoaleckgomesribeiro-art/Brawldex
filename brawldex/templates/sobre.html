Sobre o BrawlDex

Um catálogo de Brawlers inspirado em Brawl Stars, desenvolvido como projeto escolar em Django.

O projeto

O BrawlDex permite explorar um catálogo de Brawlers, ver detalhes como raridade, classe, vida e dano, além de cadastrar, editar e excluir personagens — tudo protegido por autenticação.

Tecnologias

  • Python
  • Django
  • SQLite
  • HTML + CSS
  • Bootstrap 5
  • Bootstrap Icons
  • Pillow (upload de imagens)

Autor

Projeto desenvolvido por Breno Aleck como atividade escolar de Django.

Créditos

Brawl Stars e todos os Brawlers são propriedades da Supercell. Este projeto é uma homenagem educacional, sem fins comerciais.
